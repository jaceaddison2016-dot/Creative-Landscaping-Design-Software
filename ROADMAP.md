# Creative Landscape Studio roadmap

The owner's full scope is preserved in `MASTER_PLAN.md`. Implement one manageable
milestone at a time. This branch is **Milestone A**, plus the owner's later request
to prioritize a Windows test download. Automated checks do not mark a milestone
manually accepted.

| Milestone | Outcome | Current state |
| --- | --- | --- |
| A | Actual upstream desktop editor, provenance, available validation, honest native platform gate | Source and native Windows download validated; independent review clean. Owner desktop test pending; Mac packaging deferred. |
| B | Centralized feet/inches input/display, metric compatibility, practical site/image/location/time-zone/north setup | Not started. Preserve centimeter geometry and avoid conversion drift. |
| C | Useful landscape sample and curated plant/structure palette | Not started. A's four-object smoke fixture is diagnostic only. |
| D | Landscape sun/shadow studies, clear dates/time zones, seasonal shade/heatmaps and explanations | Existing engine inherited; landscape workflow not started. |
| E | Landscape-focused workspace, schedules and trustworthy exports | Not started. Existing full editor and exports retained. |
| F | Supported signed Windows/Mac downloads, native manual QA and release process | Not complete. A's unsigned Windows Actions artifact is an early test download. |

Windows x64 comes first by owner direction. macOS remains in the broader plan;
architecture choice, native packaging, manual QA, signing/notarization remain
separate work. No universal Mac binary is promised, and no Mac hardware was chosen.

Land F/X is an ambition for future landscape workflows, not a compatibility,
feature parity, professional accuracy, affiliation or certification claim.
Do not merge this draft until the owner reports the manual checklist result.
